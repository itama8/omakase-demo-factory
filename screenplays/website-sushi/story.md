# Screenplay: Sushi check

The website's Sushi clip, from the website video kit.

Sewer check holds a conduit table, with the CPHEEO manual open beside it. Ask Sushi which conduits fall below the minimum velocity. Sushi answers and cites the manual (Table 3.9, p. 3-26). Click the citation and the PDF jumps to the table. Merge the answer into the note.

This uses live Gemini (`sushi: gemini`, with the key in GEMINI_API_KEY or OMK_KEY), so the answer's words vary between takes; the take checks only that it finished and cites the PDF. The wait for the answer is cut to a second either side. The conduit data is illustrative; the manual citation is real.
