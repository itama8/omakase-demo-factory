# Screenplay: Cache study

A compact engineering workflow in the real app: name a cache-study note, tag it into a project, finish a sentence with inline Sushi, ask for a small miss-rate table, and merge the answer. Add a chart from a CSV. End by demonstrating dictation review and insertion with the app's fixture transcript.

Quiet framing, short captions, no backing music. This is a controlled example: Sushi replies and the dictation transcript are scripted. It exercises the new reusable interactions without a live provider or microphone.
